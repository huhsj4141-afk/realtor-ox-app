공인중개사 앱 PC 일꾼 설치 (처음 한 번, 15분쯤)

1. 구글 드라이브 PC 앱 설치
   - google.com/drive/download 에서 "Drive for desktop"을 설치하고 휴대폰과 같은 구글 계정으로 로그인해요.
   - 파일 탐색기에 "Google Drive (G:)" 같은 드라이브가 생기면 돼요.

2. 파이썬 설치
   - python.org/downloads 에서 최신 버전을 받아 설치해요.
   - 설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크하세요.

3. 일꾼 파일 받기
   - github.com/huhsj4141-afk/realtor-ox-app 의 pc 폴더에서
     worker.py, 시작.bat, 자동시작_설치.bat 세 파일을 받아요.
   - C:\realtor-pc 처럼 영어 이름 폴더를 만들어 넣어요. 구글 드라이브 안에는 넣지 마세요.

4. AI 키 넣기 (채팅으로 보내지 마세요)
   - aistudio.google.com 에서 "Get API key"로 PC 전용 키를 하나 만들어요.
     (지금 쓰는 키와 같은 프로젝트에 만들면 돼요. 한도는 같이 나눠 써요.)
   - 같은 폴더에 메모장으로 key.txt 를 만들고, 키 한 줄만 붙여 넣고 저장해요.

5. 자동 시작 설치
   - 자동시작_설치.bat 을 더블클릭해요.
   - "완료!"가 나오면 끝이에요. 이제 PC를 켤 때마다 저절로 시작돼요.
   - 처음 실행하면 구글 드라이브에 "공인중개사\앱" 폴더와
     질문함.json, 답함.json 파일이 생겨요. (1~2분 뒤 동기화)
   - 폴더를 못 찾는다고 나오면(worker.log 확인), 같은 폴더에 folder.txt 를 만들고
     예: G:\내 드라이브\공인중개사\앱  처럼 경로 한 줄을 적어 주세요.

6. 휴대폰 앱 연결
   - 앱 ⚙ 설정 → "🖥 PC 일꾼: 연결 안 됨"을 눌러요.
   - 드라이브 › 공인중개사 › 앱 에서 질문함.json 을 고르고, 이어서 답함.json 을 골라요.
   - 버튼에 "연결됨 · PC 확인 ○분 전"이 보이면 완성이에요.

확인·문제 해결
- 기록: 일꾼 폴더의 worker.log
- "오늘 한도 끝" → 오후 5시 이후 자동으로 이어서 해요.
- 멈추기: 작업 관리자에서 pythonw 끄기 / 자동 시작 빼기:
  Win+R → shell:startup → 중개사앱_일꾼.bat 삭제
- PC 절전 모드에서는 일하지 않아요. 설정 → 전원에서 "절전 모드: 안 함"으로 해 두세요.
